Enhanced Firebird database driver for Laravel, with full support for Firebird 2.5 through 5.0, Dialect 1 and 3, and comprehensive schema introspection.

> Fork of [harrygulliford/laravel-firebird](https://github.com/harrygulliford/laravel-firebird) with 100+ methods, version-aware grammar, and Dialect 1 support.

## Version Support

| | Versions |
|---|---|
| **PHP** | 8.2+ |
| **Laravel** | 12, 13 |
| **Firebird** | 2.5, 3.0, 4.0, 5.0 |
| **Dialect** | 1 (InterBase legacy), 3 (modern) |

## Installation

```bash
composer require harrygulliford/laravel-firebird:4.1.x-dev
```

Add the repository to your `composer.json` if using the ptavant fork:

```json
{
    "repositories": [
        {
            "type": "vcs",
            "url": "git@github.com:ptavant/laravel-firebird.git"
        }
    ]
}
```

The package auto-registers via Laravel's package discovery.

## Configuration

Add a connection in `config/database.php`:

```php
'firebird' => [
    'driver'         => 'firebird',
    'server_version' => 3,                 // 2, 3, 4, or 5
    'dialect'        => 3,                 // 1 or 3
    'host'           => env('DB_HOST', 'localhost'),
    'port'           => env('DB_PORT', '3050'),
    'database'       => env('DB_DATABASE', '/path/to/database.fdb'),
    'username'       => env('DB_USERNAME', 'SYSDBA'),
    'password'       => env('DB_PASSWORD', 'masterkey'),
    'charset'        => env('DB_CHARSET', 'UTF8'),
    'role'           => null,              // e.g. 'RDB$ADMIN'
    'prefix'         => '',
],
```

### Configuration Parameters

| Parameter | Required | Default | Description |
|-----------|----------|---------|-------------|
| `driver` | Yes | | Always `firebird` |
| `server_version` | No | `3` | Target Firebird major version. Controls SQL syntax generation |
| `dialect` | No | `3` | SQL dialect. Set to `1` for legacy InterBase databases |
| `host` | Yes | | Server hostname or IP |
| `port` | No | `3050` | Firebird port |
| `database` | Yes | | Database alias or absolute path to `.fdb` file |
| `username` | Yes | | Database user |
| `password` | Yes | | Database password |
| `charset` | No | `UTF8` | Connection character set (`UTF8`, `ISO8859_1`, `WIN1252`, `NONE`) |
| `role` | No | `null` | SQL role (e.g. `RDB$ADMIN`) |

### Server Version

The `server_version` parameter controls SQL generation without querying the server:

| Value | Firebird | SQL Syntax |
|-------|----------|------------|
| `2` | 2.5 | `SELECT FIRST n SKIP m`, `SMALLINT` for boolean, `CASE WHEN EXISTS`, no `IDENTITY` |
| `3` | 3.0 | `FETCH FIRST ... ROWS ONLY`, native `BOOLEAN`, `GENERATED BY DEFAULT AS IDENTITY` |
| `4` | 4.0 | `LATERAL JOIN`, `TIMESTAMP WITH TIME ZONE`, 63-character identifiers |
| `5` | 5.0 | `SKIP LOCKED`, partial indexes, `MERGE ... RETURNING` |

### Dialect

| Value | Behavior |
|-------|----------|
| `1` | InterBase legacy. `DATE` includes time. Double-quotes are string literals. Identifiers unquoted |
| `3` | Modern (default). `DATE` is date-only. Double-quotes wrap identifiers. `BOOLEAN` and `TIME` available |

## Usage

### Query Builder

```php
// All standard Laravel query builder methods work
DB::connection('firebird')->table('USERS')->get();
DB::connection('firebird')->table('USERS')->where('NAME', 'containing', 'smith')->get();
DB::connection('firebird')->table('USERS')->insertGetId(['NAME' => 'John'], 'ID');
```

### Eloquent

```php
class User extends Model
{
    protected $connection = 'firebird';
    protected $table = 'USERS';
    protected $primaryKey = 'ID';
}
```

### Stored Procedures

```php
// Selectable procedure
DB::connection('firebird')->query()->procedure('MY_PROC', [$param1])->get();

// Or via connection shortcut
DB::connection('firebird')->executeProcedure('MY_PROC', [$param1]);
```

### Auto-increment with Generators

Firebird 2.5 does not support `IDENTITY` columns. Use generators with the Eloquent `creating` event:

```php
class MyModel extends Model
{
    protected static function booted(): void
    {
        static::creating(function ($model) {
            if (! $model->getKey()) {
                $result = $model->getConnection()
                    ->selectOne('SELECT GEN_ID(GEN_MY_TABLE_ID, 1) AS ID FROM RDB$DATABASE');
                $model->ID = $result->ID;
            }
        });
    }
}
```

On Firebird 3.0+, use `$table->id()` in migrations which generates `GENERATED BY DEFAULT AS IDENTITY`.

## Feature Matrix

### Query Grammar

| Feature | Method | FB 2.5 | FB 3.0+ |
|---------|--------|--------|---------|
| Select with limit/offset | `->limit()->offset()` | `FIRST/SKIP` | `FETCH FIRST/OFFSET ROWS` |
| Insert | `->insert()` | Per-row (no multi-row VALUES) | Per-row (no multi-row VALUES) |
| Insert get ID | `->insertGetId()` | `RETURNING` clause | `RETURNING` clause |
| Upsert | `->upsert()` | `UPDATE OR INSERT ... MATCHING` | `UPDATE OR INSERT ... MATCHING` |
| Insert or ignore | `->insertOrIgnore()` | `UPDATE OR INSERT` | `UPDATE OR INSERT` |
| Truncate | `->truncate()` | `DELETE FROM` | `DELETE FROM` |
| Lock | `->lockForUpdate()` | `WITH LOCK` | `WITH LOCK` |
| Exists | `->exists()` | `CASE WHEN EXISTS` | `SELECT EXISTS` |
| Lateral join | `->joinLateral()` | Not supported | FB 4.0+ |

### Firebird-specific Operators

| Operator | Description |
|----------|-------------|
| `containing` | Case-insensitive substring search |
| `starting with` | Prefix match (index-friendly) |
| `similar to` | SQL standard regular expressions |
| `is distinct from` | NULL-safe comparison |

### Schema Grammar

| Feature | FB 2.5 | FB 3.0+ |
|---------|--------|---------|
| Create/drop table | Yes | Yes |
| Global temporary table | Yes | Yes |
| Drop if exists | `EXECUTE BLOCK` workaround | `EXECUTE BLOCK` workaround |
| Add/drop/rename column | Yes | Yes |
| Change column type | Yes | Yes |
| Auto-increment (IDENTITY) | No (use generators) | `GENERATED BY DEFAULT AS IDENTITY` |
| Boolean type | `SMALLINT` | Native `BOOLEAN` |
| TZ types | `TIMESTAMP`/`TIME` fallback | FB 4.0+: native TZ types |
| Indexes, foreign keys | Yes (31-char name limit) | Yes (63-char on FB 4.0+) |
| Sequences (create/drop/restart) | Yes | Yes |
| Table/column comments | Yes | Yes |
| Column introspection | Full metadata | Full metadata |
| Index introspection | Yes | Yes |
| Foreign key introspection | Yes | Yes |
| `dropAllTables` / `dropAllViews` | Yes (FK-aware) | Yes (FK-aware) |

### Type Mapping

| Laravel | Firebird |
|---------|----------|
| `integer` / `bigInteger` / `smallInteger` | `INTEGER` / `BIGINT` / `SMALLINT` |
| `float` / `double` / `decimal` | `FLOAT` / `DOUBLE PRECISION` / `DECIMAL(t,p)` |
| `string(n)` / `char(n)` | `VARCHAR(n)` / `CHAR(n)` |
| `text` / `longText` | `BLOB SUB_TYPE TEXT` |
| `boolean` | `BOOLEAN` (FB 3.0+) or `SMALLINT` (FB 2.5) |
| `json` / `jsonb` | `BLOB SUB_TYPE TEXT` |
| `date` / `dateTime` / `timestamp` | `DATE` / `TIMESTAMP` |
| `dateTimeTz` | `TIMESTAMP WITH TIME ZONE` (FB 4.0+) or `TIMESTAMP` |
| `binary` | `BLOB SUB_TYPE BINARY` |
| `uuid` | `CHAR(36)` |
| `enum` | `VARCHAR(255)` with `CHECK` constraint |

## Limitations

- **No multi-row INSERT VALUES**: Firebird does not support `VALUES (), (), ()`. Multiple rows generate separate `INSERT` statements.
- **No DELETE/UPDATE with JOIN**: Use subqueries or `MERGE` instead.
- **No TRUNCATE TABLE**: Uses `DELETE FROM` as workaround.
- **No INTERSECT/EXCEPT**: Not supported in any Firebird version.
- **No RENAME TABLE**: Not supported. Recreate table instead.
- **No native JSON functions**: JSON stored as `BLOB SUB_TYPE TEXT`.
